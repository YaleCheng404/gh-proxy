GitHub Accelerator

粘贴 Release 文件、源码压缩包或单个文件的链接即可下载。链接可以省略协议头。

也可以在资源链接前加上本站地址。支持 raw、Gist、GitHub API、GitLab 和 Pages 资源。

Clone 用法：git clone https://proxy.example.com/https://github.com/user/project.git

项目文件夹不能直接下载。

可用链接示例：

  • 分支源码：https://github.com/user/project/archive/main.zip
  • Release 源码：https://github.com/user/project/archive/v0.1.0.tar.gz
  • Release 文件：https://github.com/user/project/releases/download/v0.1.0/example.zip
  • 分支文件：https://github.com/user/project/blob/main/filename
